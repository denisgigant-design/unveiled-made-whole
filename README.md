# Made Whole — an Unveiled Bible game

Play: https://denisgigant-design.github.io/unveiled-made-whole/

A mobile-friendly Bible game exploring body, soul and spirit through twelve everyday moments, KJV Scripture, explanations, scoring and targeted practice.

## Manage your game

This repository contains your game files and their version history. The website is published from the `main` branch, root folder, through GitHub Pages.

- Hosting controls: repository **Settings → Pages**.
- Change a question or explanation: edit `game-core.mjs`.
- Change the page or design: edit `index.html` or `styles.css`.
- Each change committed to `main` publishes automatically.

The best score is saved in the player’s browser. No accounts, database, build step or runtime dependencies are required.

## Validate the game

Run `node checks.mjs` before publishing changes to game logic.

The body, soul and spirit categories are a Christian teaching model. Scripture quotations are identified separately from commentary.
